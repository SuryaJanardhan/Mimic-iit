# Content Generation Strategy

## 1. Objective
To generate high-value, tech-focused LinkedIn posts that drive genuine engagement without appearing as generic AI content ("AI slop").

## 2. Key Content Sources
1. **Trending GitHub Repositories**: High-star repos, new open-source breakthroughs, developer tools.
2. **AI & Tech Trends**: LLM advancements, agentic AI frameworks, infrastructure developments.
3. **Historical Performance Feedback**: Analyzing top performing past posts to double down on formats that work.

## 3. Strict Style & Formatting Rules

### A. Zero Hashtags Policy
- Absolutely no hashtags (#AI, #Tech, etc.) attached to posts.
- Keeps post presentation clean, executive, and non-spammy.

### B. High Value Text Structure
- Hook: Direct statement or question highlighting a real problem or breakthrough.
- Core Insight: Short, clear explanation of why it matters.
- Key Takeaways: Bullet points for quick readability.
- Call to Action (CTA): Open question to spark meaningful discussion in comments.

### C. Visual Assets (No AI Slop)
- Attach professional graphics, architecture diagrams, or clean screenshots when available.
- Avoid low-quality, generic AI generated stock images.

## 4. Prompt Engineering Blueprint
Prompts sent to the LLM must enforce:
- Professional tone suitable for senior software engineers and architects.
- Strict constraint of 0 hashtags.
- Markdown formatting optimized for LinkedIn line breaks.
- Context integration from recent trending repos and prior top post engagement data.
